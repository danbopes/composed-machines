# Research notes

Background research behind the composed-machine proposal. Design documents are in [../docs/](../docs/), benchmark results in [../bench/RESULTS.md](../bench/RESULTS.md).

- [RESEARCH.md](RESEARCH.md): the consolidated summary (ranked capability gaps, shipped compound entities, Wube's changes and statements, test entities, pY benchmark targets). Written 2026-11-01 from the notes below, with a second-pass section added 2026-11-02.
- [forum-requests.md](forum-requests.md): Modding interface requests for entity parts modders could not get, 2019-2026. Gathered 2026-11-01 from web-search excerpts of forums.factorio.com, checked against the 2.1.24 changelog and API reference.
- [forum-help.md](forum-help.md): Modding help and discussion threads where modders were blocked by fixed entity types. Gathered 2026-11-01 from web-search excerpts.
- [forum-threads-full.md](forum-threads-full.md): full reads of the key threads, with developer replies quoted. Read 2026-11-01 in a browser, read-only.
- [forum-dropped-features.md](forum-dropped-features.md): 53 threads, mostly in "Won't implement", about features dropped or hacked around. Read 2026-11-02 in a browser, read-only.
- [github-issues.md](github-issues.md): 176 verified findings from mods' own GitHub issues, code and READMEs. Swept 2026-11-02 with the `gh` CLI, read-only, each quote checked by two verification passes.
- [mod-library-a.md](mod-library-a.md): compound-entity patterns in mods a-m from the mod portal. Surveyed 2026-11-01 by grepping and reading each mod's control-stage Lua.
- [mod-library-b.md](mod-library-b.md): the same survey for mods n-z and 0-9, excluding pY. Surveyed 2026-11-01.
- [pyanodons.md](pyanodons.md): catalogue of the script-driven entities in the Pyanodons suite. Read from the mods' source on 2026-11-01; nothing was run.
- [wube-direction.md](wube-direction.md): what Wube has shipped for custom-entity modding (2.0.7 to 2.1.24) and what the developers have said. Gathered 2026-11-01 from the changelog, the API reference JSON and web-search excerpts.
- [CONVERSION-CANDIDATES.md](CONVERSION-CANDIDATES.md): 189 buildings from vanilla, the local mod library, pY and external mods rated FULL / PARTIAL / NO for conversion to a composed machine. Consolidated 2026-11-02 from four sweep notes (not included) plus portal download counts and the benchmark census.
