# GitHub evidence: features modders dropped, crippled or hacked because of the modding API

Research note for the composed-machine proposal. Compiled 2026-11-02
from five finder notes and two independent verification passes (verify-1, verify-2); those working notes are not
included in the public repository. Every quote below was re-fetched and matched verbatim
(whitespace-normalised) by a verifier; quotes are capped at 40 words. People are named by role, not by name.
Classifications refer to [../docs/SPEC.md](../docs/SPEC.md) (v1), [../docs/V2-PARTS.md](../docs/V2-PARTS.md) (v2 parts) and the blocker codes in
[CONVERSION-CANDIDATES.md](CONVERSION-CANDIDATES.md).

## 1. Summary

The sweep confirmed **176 findings** in **100 repositories** (GitHub plus one git.gay and one Gitea
tracker). 78 distinct Factorio mod-portal mods could be matched to those repositories, with
5,790,748 downloads between them (the figure includes flib at 1,080,680, a library most of these mods depend on; the
downloads column below is blank wherever the portal name was not confirmed). By source: 106 issues, 36 code-comment/code, 21 readme files, 11 PRs, 2 changelog files. By year:
2017 10, 2018 6, 2019 8, 2020 10, 2021 8, 2022 9, 2023 16, 2024 8, 2025 25, 2026 51, undated (READMEs, code) 25. 76 of the 151 dated findings are from 2025-2026, so most of this is current 2.0/2.1 experience, not
leftover 0.17-era complaints. **30 findings are statements that a whole building, mechanic or feature was abandoned**
(or declined, shelved, or blueprinting disabled) because of the API. **32 describe a polling workaround**
(`on_tick`, `on_nth_tick`, round-robin budgets, timers). **78 describe a hidden-entity workaround**
(hidden or invisible helpers, shells, proxies, compound/composite entities), and **13 use the
prototype-per-value or prototype-swap pattern**. These three counts come from a keyword match on each finding's
workaround and quote fields and overlap, so read them as floors. 16 findings carry weight "high" (the text names
the API or engine as the blocker and the mod is large or the cost is measured).

Coverage by the proposal: **35 findings (20%) are fixed by the v1 composed-machine type as specified**, and another
**60 (34%) by a v2 part** (settings 5, lifecycle residue 13, generation 13, heat 8, broadcast 4, circuit input 3,
continuous process 2, tile/surface 2, other small parts 10). So 95 of 176 (54%) fall inside the composed-machine
design. 5 need a one-field change on vanilla crafters (VCRAFT). 65 are fixed engine cores the proposal does not
touch (train/robot/electric networks 18, units and vehicles 12, mining 3, other cores such as inserters, loaders,
turrets and pumps 32), and 11 are cross-entity or cross-surface links that SPEC section 0 rules out. Two
caveats when presenting this to Wube. First, two findings were filed from the author's own GitHub account
(planet-muluna #376 and Corrundum #78) and must not be cited as independent community evidence; they are flagged in the
tables. The counts in this note include those two (both are V1, weight low, not abandoned); without them the totals are
174 confirmed findings, 33 fixed by v1 and 93 of 174 (53%) inside the design. Second, 6 findings come from repositories that are visibly AI-assisted (Rykon00/*, trulsjo/*, an
AI-agent PR in Daikael/*). Those are kept because they record engine behaviour measured against 2.0/2.1, but they
should be weighted below long-maintained mods. The other 87 candidates were rejected, 49 of them because 2.0 or 2.1
already solved the problem (mostly `LuaEntity.local_effect`, `on_blueprint_settings_pasted`,
`InfinityCargoWagonPrototype`, `ValvePrototype`, `raise_on_crafted`). That is evidence too: when Wube adds the
engine piece, the hack disappears (section 5).

where the portal entry's `source_url` or owner matches the repository. pybugreports rows use pyalienlife's count, because
pybugreports is the shared tracker for the whole pY suite. The Alt-F4 and dvilker rows use Rail Logistics Dispatcher
(`RailLogisticsDispatcher`, same author, source in a sibling repo). Reika_FactorioMods_Issues #5 uses EndgameCombat and #326 uses
Geothermal. Classification key: **V1** = the v1 type as specified; **V2-x** = a v2 part ([../docs/V2-PARTS.md](../docs/V2-PARTS.md));
**VCRAFT** = one field on vanilla crafters; **CORE-x** = a fixed engine core the proposal does not replace; **EXCLUDED-XENT** =
cross-entity/cross-surface, ruled out by SPEC 0.

## 6. Methods

- **When and how.** All sweeps ran on 2026-11-02, read-only, with the `gh` CLI logged in as the author's account.
  Nothing was posted, starred or forked. Five angles ran in parallel, each writing its own working note (not included in the public repository):
  - `keyword.md`: about 162 search calls. These were keyword queries through `gh api search/issues` (issues and PRs, open and closed),
    4 paged queries for issues linking `viewtopic.php?f=28` (Wube's Modding interface requests subforum), 8 GraphQL
    `type:DISCUSSION` queries and 10 `search/code` queries for README/changelog "engine limitation" / "API
    limitation" notes. About 150 issues and PRs were read in full.
  - `labels.md`: labels listed for about 50 mod repositories. Every issue under a blocked-by-engine label was read (120 issues:
    `Cannot Fix (API Limitation)`, `Waiting on API Request`, `missing-api`, `Factorio Update Required`, `base game
    bug`, `upstream`, `vanilla issue`, `rejected`, `blocked`). All issues and comments of about 110 repositories were bulk-downloaded
    (about 49k records) and grepped locally. About 60 more GitHub-wide queries were paced 4 s apart.
  - `repos-a.md`: full issue, PR and comment dumps through the core API, plus shallow clones for code comments, of the large overhaul
    and logistics mods: pybugreports (1554 items, 2518 comments), pyalienlife/pyalternativeenergy PRs, Krastorio2,
    LTN, nullius, Exotic Industries, Ultracube, Angel's, Bob's, SeaBlock, Factorissimo2, heinwessels' mods.
  - `repos-b.md`: the same treatment for planet mods and mid-size scripted-building mods at pinned commits
    (maraxsis 92d1f2d, Cerys 77a394a, planet-muluna 702dcac, Corrundum 77d22bf, castra, rubia, Paracelsin, Moshine,
    Secretas, tenebris-prime, Klonan's mods, Nanobots2, nixie-tubes, Bio_Industries_2, cargo_ships), plus Lignumis on Gitea.
  - `libraries.md`: READMEs, issues and code of the compound-entity, blueprint and move libraries (Things, bplib,
    cooperative-blueprinting, Even Pickier Dollies, PickerDollies, factorio-core-libs, flib,
    zzz-nonstandard-beacons).
- **Verification.** Two verifiers re-fetched every candidate with `gh api` (body, all comments, PR review comments,
  raw files at the cited commit, git.gay by raw fetch, Gitea by its API) and script-matched each quote verbatim.
  Verifier 1: 132 candidates, 82 confirmed and 50 rejected. Verifier 2: 131 candidates, 94 confirmed and 37 rejected. Each ALREADY-SOLVED
  call was checked against the 2.1.24 `runtime-api.json` / `prototype-api.json` published at lua-api.factorio.com. The same check confirmed what is
  still missing in 2.1.24: recipe-changed event, train-stop-limit event, entity inventory-changed event, non-electric
  roboport/beacon energy, multi-fluid fluid-box filter, container rotation, unit inventory, and furnace input beyond 1 slot
  (verify-1).
- **Counting rules for section 1.** "Polling", "hidden entity" and "prototype per value" are regex matches over each
  finding's workaround and quote (and, for hidden entities, its blocked_by) fields, so a finding can count in more than
  one. Gap counts in section 4 marked "hand count" are the URLs listed in that cell.
- **Dead ends.**
  - `wube/factorio-data` has issues disabled. Wube keeps no modding-API tracker on GitHub; requests live on forum f=28.
  - Space Exploration, Tenebris, aai-signal-transmission and equipment-gantry have no public repository.
  - pyalienlife/pyalternativeenergy and Bio_Industries_2 have issues disabled.
  - `notnotmelon/factorissimo-2-notnotmelon` returns 404 (Factorissimo 3 lives on git.gay), and `Optera/LTN` is really `0ptera/Logistic-Train-Network`.
  - `gh search issues` with quoted phrases silently returns 0 (the REST `search/issues -f q=` form works), and OR without parentheses matches about 36k unrelated hits.
  - The shared search quota returned HTTP 403 twice, so agents switched to core-API bulk dumps and mod-portal `source_url` lookups. That is more complete than keyword search.
  - GitHub Discussions were almost all noise.
  - A 2026 wave of AI-agent-authored repositories adds spec-style issues. Most were ignored; the few kept are flagged.
- **Downloads.** `https://mods.factorio.com/api/mods/<name>/full` fetched 2026-11-02. Portal names that did not resolve
  or pointed at a different repository were left blank: Wireless-Circuit-Network, Red-Alert-Harvesters, LongWarehouses,
  starcraft, SpaceTrainNetwork, Companionship, quantum-fabrication, factorio-core-libs, hexcoder-gleba-rework,
  realistic-fusion-refreshed, Zomis' "What is it Missing" (the guessed name points at another author's repo), StoneAge and
  omnimatter (source_url points at a different repository).
